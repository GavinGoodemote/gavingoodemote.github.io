# The Goodemote Report

Free static website starter for an energy research publication.

## How to update the site

1. Open the HTML file you want to change.
2. Replace the placeholder text with your report content.
3. Add a new report card to `research.html`.
4. Keep `styles.css` unchanged unless you want to adjust the design.

## Suggested next step

Sector reports use `shell-sector-report.html` as the current example. Company valuation reports can use the same header, footer, and styles in a new file such as `halliburton.html`, then be linked from the Company Valuations section in `research.html`.

## Free publishing

This site can be published for free through GitHub Pages or Cloudflare Pages. A custom domain is optional.
